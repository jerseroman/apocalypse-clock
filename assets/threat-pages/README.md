# Threat report component

Source: the supplied `apocalypse-threat-pages.zip`, SHA256
`0a468b7fdab64f608188c7323627799b9484cdb257e2c68e81b5e1ea7a88cd9e`.

The self-contained component renders the 23 reports listed in `pages.csv`.
It uses saved model outputs, not a new Monte Carlo calculation on page load.
This asset is separate from the desktop and mobile clock application.

Wix custom element source: the GitHub Pages URL for `threat-report.js`.
Registered tag: `threat-report`. A compatibility alias is also registered for
Wix editors that retain `wix-default-custom-element` on a new component.

The supplied report contents are preserved. Compatibility with the live Wix
layout must be verified separately; a syntax check is not publication proof
or scientific validation of the report claims.
